# first-pr-practice

Учебный репозиторий для первого Pull Request.

## Как это работает

1. Создаётся отдельная ветка.
2. В ней вносится небольшое изменение.
3. Открывается Pull Request в ветку main.

## Полезные команды

```bash
git switch -c my-branch   # создать ветку
git add .                 # добавить изменения
git commit -m "Message"   # зафиксировать
git push -u origin my-branch
gh pr create              # открыть Pull Request
```
